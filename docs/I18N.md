# I18N · Словарь переводов

Все строки UI и документа хранятся в объекте `DICT` в секции **7.1** файла `index.html`. Чтобы перевести интерфейс — добавить язык в словарь.

## Структура DICT

```
DICT = {
  ru: {
    "app.tagline": "...",        // точечный ключ
    "cues.empty": "...",         // точечный ключ
    "gallery.count": (n) => `${n} фото`,   // функция для плюрализации
  },
  en: { ... }    // <- добавляется аналогично
}
```

## API

Внутри React-компонентов:

```jsx
const t = useT().t;          // (key: string) => string
const tn = useT().tn;        // (key: string, n: number) => string  — для плюрализации
const { locale, setLocale } = useT();
```

Использование:

```jsx
<GroupTitle>{t("editor.fixtures")}</GroupTitle>
<Badge>{tn("gallery.count", photos.length)}</Badge>
```

## Как добавить английский

1. В `SUPPORTED_LOCALES` добавить `"en"`.
2. В `DICT` добавить блок `en: { ... }` со **всеми** ключами, что есть в `ru`.
3. Готово. `useT()` отдаст текущую локаль, переключатель — через `setLocale("en")` (UI-переключатель ещё не подключён, вызывать вручную из консоли или добавить в Topbar).

## Ключи, которые обязательно нужны в каждом языке

См. полный список в `DICT.ru`. Если ключ отсутствует в активной локали, `t(key)` вернёт сам ключ — это сигнал "не переведено".

## Правила

1. **Строки UI и текст документа — через t()**. Хардкод в JSX запрещён.
2. **Плюрализация — через функцию**: `"fixtures.total": (n) => \`Всего: ${n} шт.\``.
3. **Даты и числа** — пока через `toLocaleString(locale)` или просто строкой, без moment/dayjs.
4. **Не использовать эмодзи** в словаре — они хуже локализуются.
5. **Не делать вложенную интерполяцию** на этом этапе (KISS). Если нужны переменные — функция.

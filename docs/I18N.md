# I18N: translation dictionary

All UI and document strings live in the `DICT` object in **`src/i18n/dict.js`**. The provider and hook are in `src/i18n/I18nProvider.jsx`. Outside React (export, utils) use `makeTranslator(locale)` from `src/i18n/translate.js`. It's the same logic.

## DICT structure

The dictionary is **flat**: keys are dotted strings, not nested objects.

```js
export const SUPPORTED_LOCALES = ["ru"];

export const DICT = {
  ru: {
    "app.tagline": "...",                     // plain string
    "cues.empty": "...",
    "gallery.count": (n) => `${n} фото`,      // function: plurals / variables
  },
  // en: { ... }  ← added the same way
};
```

Key prefixes in use: `app`, `menu`, `appearance`, `replace`, `open`, `editor`, `meta`, `times`, `staff`, `plots`, `gallery`, `lightbox`, `fixtures`, `cues`, `commentary`, `doc`, `export`, `storage`, `unit`, `common`.

## API

```jsx
const { t, tn, locale, setLocale } = useT();

t("editor.fixtures")                  // → string (or the key itself if missing)
tn("gallery.count", photos.length)    // → calls the function value with the args
```

- The current locale is saved in localStorage under `tld.locale.v1`.
- If a key is missing in the active locale, `t(key)` returns the key itself. Seeing a raw key in the UI means "not translated".
- If the locale is unknown, `t` falls back to `DICT.ru`.
- Export always renders in `EXPORT_LOCALE` (`"ru"`, see `utils/exportHtml.jsx`). Change this when adding languages.

## How to add English

1. Add `"en"` to `SUPPORTED_LOCALES`.
2. Add an `en: { ... }` block to `DICT` with **all** keys from `ru`.
3. A language switcher isn't in the UI yet: call `setLocale("en")` or add one to `Topbar` in `App.jsx`.
4. Pass the current locale to the export instead of the hardcoded `"ru"`.

## Rules

1. **All UI strings and document text go through `t()` / `tn()`.** Hardcoded text is not allowed. ESLint enforces it: any Cyrillic string literal outside `dict.js` is an error, as is any text node in JSX.
2. **Plurals and variables use a function value:** `"fixtures.total": (n) => \`Всего: ${n} шт.\``. There is no `{n}` placeholder syntax: `tn()` only calls functions, so `"… {n} …"` would show a literal `{n}`.
3. **Dates and numbers:** `toLocaleString(locale)` or a plain string. No moment/dayjs.
4. **No emoji** in the dictionary.
5. **No nested interpolation** (KISS). If you need variables, use a function.
